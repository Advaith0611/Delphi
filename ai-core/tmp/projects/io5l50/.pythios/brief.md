# Pythios project brief

ARTIFACT TYPE: interactive demo

USER GOAL: Create a tool that allows users to draw a curve on a coordinate plane and automatically identifies the corresponding mathematical equation.

BUILD BRIEF:
1. Implement an HTML5 Canvas-based coordinate system (X and Y axes) where users can draw freehand curves.
2. Implement a curve-fitting algorithm (e.g., polynomial regression or least-squares fitting) to analyze the coordinates of the drawn path.
3. Display the resulting mathematical equation (e.g., y = ax^2 + bx + c) dynamically as the user draws or upon completion of the stroke.
4. Provide a "Clear" button to reset the canvas.

SUCCESS CRITERIA:
- The application successfully captures mouse/touch input to draw a continuous line on the grid.
- The system calculates and renders a text representation of the equation that approximates the drawn shape.
- The equation updates in real-time or immediately after the user finishes drawing.
